# Student-Book_Exchange-Manager
A basic student book exchange management application developed using Python and Flask.

## Project Objective

The Student Book Exchange Manager is an individual application designed to help students manage books available for exchange and exchange requests.

## Main Features

* User/Profile Management
* Book Management
* Search and Filter
* Book Exchange Requests
* Validation and Exception Handling
* Simple Reports/Dashboard

## Technology Stack

* Python
* Flask
* SQLite
* SQLAlchemy
* HTML
* CSS
* JavaScript
* Git/GitHub
* pytest
